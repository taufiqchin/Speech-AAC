# Helping Every Individual Express Their Voice

Speech AAC (Bahasa & English) is a bilingual Augmentative and Alternative Communication (AAC) mobile application designed to support individuals with complex communication needs. It combines picture-based communication, sentence building, and natural speech output to help users communicate confidently in both **Bahasa Malaysia** and **English**.

Designed specifically for the Malaysian community, Speech AAC works completely offline, provides a responsive interface for phones and tablets, and offers an intuitive communication experience for home, school, therapy, and healthcare environments.

# Why Speech AAC?

Unlike many AAC applications that primarily support English, Speech AAC is designed with Malaysian users in mind by providing bilingual communication in **Bahasa Malaysia and English**.

The application contains **818 communication icons** with speech output organised into three simple sections:

- Main communication panel
- Category selection
- Category vocabulary

Users can instantly switch languages, customise layouts, drag communication icons, and build meaningful daily sentences through an intuitive visual interface.

Speech AAC supports communication across:

- Home
- School
- Therapy sessions
- Hospitals
- Rehabilitation centres
- Community environments

# Project Vision

Speech AAC aims to make communication more inclusive, affordable, and accessible for everyone.

By combining bilingual communication, visual sentence building, offline accessibility, and a simple user interface, the application helps individuals express themselves more independently while supporting families, educators, therapists, and healthcare professionals.

The project continues to evolve through user feedback and ongoing research in assistive technology and mobile AAC.
